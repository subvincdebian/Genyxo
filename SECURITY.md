# Security policy

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/subvincdebian/Genyxo/security/advisories/new) to send a report to the maintainers. Keep vulnerability details out of public issues, pull requests, and discussions while the report is being reviewed.

Include the affected component, version or commit, the conditions needed to reproduce the issue, and its expected impact. Redact credentials, tokens, and personal data before attaching logs or examples.

Maintainers will use the private report to confirm the issue, coordinate a fix, and discuss disclosure.
